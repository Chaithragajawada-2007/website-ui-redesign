
# CampusConnect — Website UI Redesign

## Project Overview
CampusConnect is a student-focused website interface created as a website UI redesign project. It presents campus services, career opportunities, learning resources, and contact information in a clear, modern layout.

## Objective
Improve the clarity, visual hierarchy, navigation, and responsiveness of a student-focused website interface.

## Heuristic Evaluation
The following are usability issues considered during the redesign. They should be verified against the original website selected for comparison.

- Navigation should be clear and consistent.
- Important information should be easy to locate.
- Text and backgrounds should have sufficient contrast.
- Buttons and links should have clear labels.
- Content should adapt to mobile screens.

## Design Improvements
- Clear navigation and section headings.
- Consistent typography, spacing, and button styles.
- Organized service cards.
- Clear calls to action.
- Responsive mobile navigation and layouts.

## Mood Board and Style Guide
- Primary color: Blue (#5368E8)
- Main text: Navy (#17243B)
- Background: White and light grey
- Typography: Manrope and DM Sans
- Style: Minimal, modern, and student-friendly

## High-Fidelity Mockup
The website includes a hero section, dashboard illustration, service cards, about section, contact form, and footer.

## Responsive Design
CSS media queries adapt the layout for desktop, tablet, and mobile devices.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git
- GitHub Pages

## Testing
Test the navigation, mobile menu, contact form demonstration, and layout at different screen widths before submission.

## Limitations
The contact form displays a demonstration message only. It does not send or store messages. The dashboard is illustrative and does not connect to a real campus system.

## Conclusion
This project demonstrates interface redesign, visual hierarchy, responsive web development, and basic interaction design.
